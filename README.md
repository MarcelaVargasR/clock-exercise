# 🕒 JavaScript Clock

This is a simple clock application created using HTML, CSS, and Vanilla JavaScript. It displays the current time and updates every second.

## 🔧 Features

- ⏱ Real-time clock
- 🖥️ Clean and simple design
- 💻 Built with HTML, CSS, and JavaScript
- 📱 Responsive layout
